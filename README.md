# criscgarces.github.io

Personal academic site, built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and served by GitHub Pages (stock Jekyll build, no Actions needed).

| What | Where |
| --- | --- |
| Site settings, sidebar (name, photo, links) | `_config.yml` |
| Home / bio | `_pages/about.md` |
| Publications (one file per paper) | `_publications/` |
| Teaching (one file per course) | `_teaching/` |
| CV page | `_pages/cv.md` |
| CV PDF | `files/cv.pdf` |
| Header menu | `_data/navigation.yml` |
| Profile photo | `images/profile.png` |

Local preview (optional): `docker compose up`, then open http://localhost:4000.
